# Photographs of Blackburn G-AANI

These four images are embedded in the offline simulator. Each image was resized and JPEG-recompressed from the linked source. The image files retain their respective Creative Commons Attribution-ShareAlike licences.

- [1912 Blackburn Type D Monoplane (G-AANI)](https://commons.wikimedia.org/wiki/File:1912_Blackburn_Type_D_Monoplane_(G-AANI)_(40992016760).jpg), Alan Wilson. The surviving aircraft at Old Warden, 3 June 2018. [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)
- [Blackburn Type D cockpit](https://commons.wikimedia.org/wiki/File:Blackburn_Type_D_cockpit.JPG), TSRL. The real control wheel at Old Warden, 22 September 2013. [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- [1912 Blackburn Type D Monoplane [G-AANI / BAPC-5]](https://commons.wikimedia.org/wiki/File:1912_Blackburn_Type_D_Monoplane_-G-AANI_BAPC-5-_(52608247489).jpg), Alan Wilson. The restored Blackburn in Hangar 5, Old Warden, 2 January 2023. [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)
- [Blackburn Monoplane - Season Premiere Airshow 2018](https://commons.wikimedia.org/wiki/File:Blackburn_Monoplane_-_Season_Premiere_Airshow_2018_(41272925715).jpg), Airwolfhound. G-AANI flying at the 2018 Season Premiere Airshow. [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)
